# Statistics over the five Haiku runs

Runs: baseline trials 1-2 (description + hints) and one trial each of fdj, docetl, sqlverify. Same 104 questions,
same validators. Generated by `experiments/stats_methods.py`.

No run differs from either baseline trial at p < 0.05; the two baseline trials themselves differ by 15 discordant questions.

## 2. Noise floor from untouched questions

On questions a method did not touch, the condition run is an independent draw of the baseline condition.

| Run | Untouched questions | Correct (run / t1 / t2) | Discordant with t1 | Discordant with t2 |
|---|---|---|---|---|
| fdj | 81 | 53 / 54 / 54 | 21 | 17 |
| docetl | 82 | 61 / 59 / 56 | 12 | 15 |
| sqlverify | 95 | 63 / 60 / 57 | 11 | 14 |

Questions untouched by every method: 64. Across the five runs 22 of them are flaky (right in 1-4 runs).
Treating each question as Bernoulli with its five-run pass rate, one run's correct count on these 64 questions has
SD 2.1; the difference between two independent runs has SD 2.9 questions.
